# 고윳값 사냥꾼

행렬 기계를 통과해도 **방향이 안 바뀌는 화살표(고유벡터)**를 찾는 게임으로 시작해, 슈뢰딩거 방정식 **Hψ = Eψ**가 같은 고윳값 문제라는 것을 손으로 체험하는 앱입니다. 「수학자의 양자역학」 제2강 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/eigen-hunter/**

## 특징
- 🎯 방향 찾기: 6스테이지(늘이는 기계·강의 속 기계·뒤집는 기계·비스듬한 기계·무작위 대칭 기계·회전 기계), 기록 저장
- 🎸 기타줄·계단: 정상 상태(확률은 멈추고 위상 바늘만 회전), 1+2 섞기 맥놀이, 우물 폭에 따른 에너지 계단(∝n², ∝1/L²), 우물 개수에 따른 띠(밴드) 형성
- 💻 컴퓨터 풀이: 격자점 개수에 따른 고윳값 수렴(폭 5 nm: 점 10개 14.94 → 50개 15.04 meV), 삼중대각 해밀토니안 행렬 시각화
- 퀴즈 5문항(11문항 중 무작위)

에너지 값은 자유전자 질량의 단순 우물 모형 기준입니다.
